# خطة بناء تطبيق "تتبع" — إدارة الديون والمصاريف

تطبيق ويب احترافي بواجهة عربية RTL مودرن، يعمل كـ PWA قابل للتثبيت، مع تسجيل دخول جوجل وحفظ البيانات في السحابة، ودعم تعدد العملات وتصدير التقارير بصيغتي PDF و Excel.

---

## 1) الميزات الرئيسية

### أ. الديون (مستحقة لي / مستحقة عليّ)

- إضافة دين باسم الشخص، المبلغ، العملة، تاريخ الاستحقاق، ملاحظات
- نوع الدين: **لي** (دائن) أو **عليّ** (مدين)
- **دفعات جزئية**: تسجيل كل دفعة بتاريخها ومبلغها، مع حساب الرصيد المتبقي تلقائياً
- **سجل جهة الاتصال**: صفحة لكل شخص تعرض جميع ديونه السابقة والحالية وصافي الرصيد
- **تذكيرات الاستحقاق**: شارة تنبيه داخل التطبيق + إشعارات Push (عبر PWA) قبل موعد الاستحقاق بيوم/3 أيام
- فلترة: الكل / مفتوحة / مسددة / متأخرة

### ب. المصاريف

- **فئات عامة جاهزة** (طعام، مواصلات، فواتير، صحة، تسوق، ترفيه...) + إنشاء فئات مخصصة
- **مشاريع/محافظ منفصلة** (مثل: رحلة دبي، مصاريف السيارة) كل واحدة بميزانية اختيارية ورصيد مستقل
- كل مصروف: المبلغ، العملة، الفئة، المشروع (اختياري)، التاريخ، ملاحظة، إيصال صورة (اختياري)
- شريط تقدم للميزانية لكل مشروع

### ج. تعدد العملات

- اختيار العملة لكل معاملة على حدة
- عملة افتراضية قابلة للتغيير من الإعدادات
- عرض المجاميع لكل عملة منفصلة (بدون تحويل تلقائي لتجنب أخطاء أسعار الصرف)

### د. التقارير والتصدير

- **PDF** منسق احترافياً بالعربية (RTL) مع شعار التطبيق، ملخص، جداول
- **Excel/CSV** للبيانات الخام
- تقارير: ديون مفتوحة، كشف حساب شخص، مصاريف فترة، مصاريف مشروع
- فلترة بالفترة الزمنية قبل التصدير

### هـ. تسجيل الدخول

- **Google OAuth** فقط (عبر وسيط Lovable)
- صفحة `/auth` للترحيب وزر تسجيل الدخول
- إنشاء profile تلقائياً عند أول دخول

### و. PWA

- قابل للتثبيت على iOS/Android/Desktop
- أيقونات، manifest، اسم بالعربية
- شاشة splash، theme color
- (الوضع الأوفلاين الكامل خارج النطاق الافتراضي — يمكن إضافته لاحقاً)

## 2) التصميم

- **اللغة**: عربية بالكامل، RTL على مستوى `<html dir="rtl">`
- **الطابع**: مودرن، نظيف، Glassmorphism خفيف، ألوان هادئة (أزرق-تركواز أساسي، أخضر للدائن، أحمر للمدين)
- **خط عربي**: Cairo أو IBM Plex Sans Arabic
- **تنقّل**: شريط سفلي على الموبايل (لوحة | ديون | مصاريف | تقارير | الإعدادات)، شريط جانبي على الديسكتوب
- **لوحة رئيسية**: بطاقات إحصائية (إجمالي لي / عليّ / مصاريف الشهر) + رسوم بيانية (Recharts)
- متجاوب بالكامل، وضع داكن وفاتح

## 3) البنية التقنية

- TanStack Start + React + Tailwind + shadcn
- **Lovable Cloud** لقاعدة البيانات + المصادقة + التخزين (للإيصالات)
- Google Sign-In عبر وسيط Lovable
- Recharts للرسوم
- jsPDF + jspdf-autotable (مع خط عربي مدمج) للتصدير PDF
- xlsx (SheetJS) لتصدير Excel
- vite-plugin-pwa للـ PWA

### الصفحات (Routes)

- `/auth` — تسجيل الدخول (عام)
- `/_authenticated/` — اللوحة الرئيسية (Dashboard)
- `/_authenticated/debts` — قائمة الديون + إضافة/تعديل
- `/_authenticated/debts/$id` — تفاصيل دين + دفعاته
- `/_authenticated/contacts/$name` — سجل جهة اتصال
- `/_authenticated/expenses` — قائمة المصاريف
- `/_authenticated/projects` — قائمة المشاريع/المحافظ
- `/_authenticated/projects/$id` — تفاصيل مشروع
- `/_authenticated/reports` — تقارير وتصدير
- `/_authenticated/settings` — الإعدادات (العملة الافتراضية، الفئات)

### قاعدة البيانات (Lovable Cloud)

- `profiles` (id, display_name, default_currency, avatar_url)
- `contacts` (id, user_id, name, phone, notes)
- `debts` (id, user_id, contact_id, direction['owed_to_me'|'owed_by_me'], amount, currency, due_date, status, notes)
- `debt_payments` (id, debt_id, amount, paid_at, notes)
- `categories` (id, user_id, name, icon, color, is_default)
- `projects` (id, user_id, name, budget, currency, icon, color, status)
- `expenses` (id, user_id, category_id, project_id?, amount, currency, spent_at, note, receipt_url)
- جميعها مع RLS صارم (`auth.uid() = user_id`)
