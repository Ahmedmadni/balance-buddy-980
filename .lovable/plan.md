
# خطة تطوير منصة رصد

سأنفذ المتطلبات على 5 محاور مع الحفاظ على قاعدة البيانات الحالية وإضافة الجداول/الحقول الناقصة فقط.

## المحور 1 — تفعيل إضافة الدخل بالكامل
- مكوّن جديد `IncomeForm` مستقل (بدل إعادة استخدام WalletTxForm) يحتوي:
  - مبلغ + عملة + تاريخ + ملاحظات
  - **اختيار المحفظة الهدف** (إجباري)
  - **مصدر الدخل**: راتب / دخل إضافي / أرباح استثمار / هدية / **مخصص** (يضيفه المستخدم ويُحفظ في `wallet_tx_categories` بنوع `inflow`)
- يحفظ في `wallet_transactions` بنوع `deposit` مع `category_id` → ينعكس تلقائياً على رصيد المحفظة عبر `computeWalletBalance` وعلى `transactions` عبر تريغر المرحلة 1.
- ربط زر "دخل" في QuickActionsRow + زر "إضافة دخل" في الصفحة الرئيسية + في صفحة المحافظ.

## المحور 2 — بطاقة "مصاريف الشهر" الحية
- استعلام `transactions` للشهر الميلادي الحالي حيث `type='expense'`.
- مقارنة بالشهر السابق (نسبة ↑/↓ ملوّنة).
- تحديث فوري عبر React Query invalidation (موجود فعلياً مع التريغرز).

## المحور 3 — استثمارات بحقول ديناميكية
- إضافة عمود `meta jsonb` و `subtype text` للجدول `investments` (إن لم يوجد).
- نموذج `InvestmentForm` ديناميكي حسب `kind`:
  - **أسهم**: ticker, shares, price_per_share, market → `current_value = shares * price`
  - **ذهب**: gold_type (سبائك/مجوهرات)، grams، price_per_gram، karat → `value = grams * price * (karat/24)`
  - **عملات رقمية**: symbol, units, unit_price → `value = units * price`
  - **عقارات**: property_name, current_value, annual_yield
  - **أخرى**: حقول key/value مخصصة
- حفظ الحقول الخاصة في `meta`، والقيمة الإجمالية في `current_value`.

## المحور 4 — زكاة متعددة العملات
- في صفحة الزكاة:
  - اختيار **العملة الأساسية** (افتراضي SAR).
  - جدول أسعار صرف قابل للتعديل يدوياً (موجود جزئياً عبر `SAR_RATES`) + إمكانية التعديل لكل عملة.
  - تحويل جميع الأوعية إلى العملة الأساسية وعرض **الإجمالي الموحّد** + النصاب بالعملة الأساسية + الزكاة 2.5%.
  - الإبقاء على التفصيل لكل عملة كمرجع.

## المحور 5 — أنواع الزكاة الشرعية (وحدة مستقلة)
- تبويب جديد داخل `/app/zakat` باسم **"زكاة الأنعام والثمار"** يحتوي حواسب مستقلة:
  - **الإبل**: جدول الأنصبة (5→شاة، 25→بنت مخاض…)
  - **البقر**: (30→تبيع، 40→مسنة…)
  - **الغنم**: (40→شاة، 121→شاتان…)
  - **الحبوب والثمار**: نصاب 653 كجم، 10% بعلي / 5% بمؤونة
  - **الركاز والمعادن**: 20% للركاز، 2.5% للمعادن
- حسابات Front-end فقط (لا تُحفظ في DB، لا تؤثر على التقارير).

## المحور 6 — PWA + شعار المنصة
- إعادة أيقونة المحفظة كشعار في الشريط العلوي وفي `manifest.webmanifest`.
- التحقق من `manifest.webmanifest` (الأيقونات، theme_color، display: standalone) لتفعيل التثبيت على الموبايل.

## ترتيب التنفيذ (دفعة واحدة)
1. **هجرة DB**: إضافة `subtype` و `meta` لـ `investments` (إن لزم).
2. **IncomeForm + ربطها** في QuickActions/Wallets/Index.
3. **بطاقة مصاريف الشهر** الحيّة + مقارنة.
4. **InvestmentForm ديناميكي**.
5. **زكاة موحّدة + تبويب الأنصاب الشرعية**.
6. **شعار + manifest**.

## ملاحظات
- لن أُعدّل `wallets/contacts/debts/recurring_expenses` أو منطق RLS.
- جميع التغييرات تحترم RTL والعربية.
- React Query سيُعيد جلب البيانات تلقائياً بعد كل عملية.
