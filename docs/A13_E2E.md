# A13 browser regression checks

The Playwright suite provides a small launch-safety net without mutating customer
data.

## Default CI coverage

`bun run test:e2e` always checks the public sign-in page, access control for the
authenticated application, and the public legal pages. GitHub Actions runs these
checks in Chromium on every pull request and push to `main`.

## Optional authenticated coverage

Authenticated smoke checks run only when both `E2E_EMAIL` and `E2E_PASSWORD` are
available. Use a dedicated test account in a non-production Supabase project and
set `E2E_BASE_URL` to that staging deployment when required. The suite obtains a
short-lived session through Supabase Auth and checks core routes without creating,
editing, or deleting records.

Never provide a production user's credentials. Any future mutation scenarios must
use disposable data and a non-production environment with explicit cleanup.
